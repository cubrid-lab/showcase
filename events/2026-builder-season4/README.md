# 빌더 시즌4 — CUBRID Kubernetes Operator

CUBRID Kubernetes Operator의 시즌4 프로그램 발표 자료를 회차별로 관리합니다.
프로그램 공식 명칭은 전달받은 “시즌4 빌더” 공지를 기준으로 임시 표기했습니다.

## 발표자료

| 회차 | 최신 HTML 발표 (`main` 기준) | 제출용 PDF·PPTX | 일정·제출 안내 |
|---|---|---|---|
| 1차 검증 | [한국어 발표](https://cubrid-lab.github.io/showcase/events/2026-builder-season4/01-validation/ko/) · [English slides](https://cubrid-lab.github.io/showcase/events/2026-builder-season4/01-validation/en/) | [2026-10-28 제출본](https://github.com/cubrid-lab/showcase/releases/tag/builder-season4-validation-2026-10-28): 한국어 [PDF](https://github.com/cubrid-lab/showcase/releases/download/builder-season4-validation-2026-10-28/operator-first-validation.ko.pdf) · [PPTX](https://github.com/cubrid-lab/showcase/releases/download/builder-season4-validation-2026-10-28/operator-first-validation.ko.pptx), English [PDF](https://github.com/cubrid-lab/showcase/releases/download/builder-season4-validation-2026-10-28/operator-first-validation.en.pdf) · [PPTX](https://github.com/cubrid-lab/showcase/releases/download/builder-season4-validation-2026-10-28/operator-first-validation.en.pptx) | [발표 안내](01-validation/) |

HTML 발표는 `main`이 바뀔 때마다 다시 만들어지므로 릴리스의 PDF·PPTX보다 새로울 수 있습니다. PDF·PPTX는 릴리스에 적힌 원본 커밋에서 출력한 고정본입니다. 현재 자료는 이야기·도식·발표자 메모를 담은
한국어·영어 각 18장 발표자료입니다. 2026-10-20 실행 근거를 바탕으로 2026-10-22에 내용을 확장했고, 2026-10-25 백업 복원 결과를 더했습니다. [한국어 원본](../../presentation/decks/2026-builder-season4/01-validation/slides.ko.md)과
[영어 원본](../../presentation/decks/2026-builder-season4/01-validation/slides.en.md)은 GitHub에서 확인할 수 있습니다.
로컬 실행과 PPTX·PDF 출력 방법은 [1차 검증 안내](01-validation/#웹-원본에서-발표와-내보내기)를 참조합니다.

2차 검증과 최종 발표는 준비를 시작할 때 각각 `02-validation/`, `03-final/`을
추가하고 이 목록에서 연결합니다. 새 발표는 이전 자료를 바탕으로 작성하되,
각 회차의 원본과 실제 제출한 파일은 구분해 보존합니다.
