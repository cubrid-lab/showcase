# CUBRID Kubernetes Operator — 1차 검증 발표 구성안

상태: 내용 작성 전 골격. `[작성]`과 `[확인]`을 채운 뒤 PPTX로 제작합니다.
일정·제출 형식은 [발표 안내](README.md), 영어 대응본은 [SLIDES.en.md](SLIDES.en.md)를 참조합니다.

총 발표 시간 10분(600초), 질의응답 10분. 아래 시간 배분은 제안이며 공지의
7개 필수 항목을 모두 포함합니다. 데모 시간은 별도로 배정하지 않습니다.

| 슬라이드 | 필수 항목 | 시간 |
|---|---|---|
| 1 | 프로젝트 소개, 팀원 소개 | 60초 |
| 2 | 해결하려는 문제와 그 문제를 겪는 대상 | 90초 |
| 3 | 현재 해결 방식과 기존 오픈소스의 한계 | 90초 |
| 4 | 팀이 제안하는 해결 방법 | 90초 |
| 5 | 아키텍처 초안 | 120초 |
| 6 | 12주 로드맵, 팀원별 역할, 첫 버전 공개 범위 | 90초 |
| 7 | 함께 논의하거나 의견을 구하고 싶은 내용 | 60초 |
| 합계 | | 600초 |

## 1. 프로젝트 소개, 팀원 소개 — 60초

- 프로젝트: CUBRID Kubernetes Operator
- `[작성]` 어떤 사용자의 어떤 운영 작업을 돕는지 한 문장으로 설명
- `[확인]` 팀명, 팀원 이름, 관련 경험, 프로젝트에서의 역할
- 저장소: https://github.com/cubrid-lab/cubrid-kubernetes-operator

## 2. 해결하려는 문제와 그 문제를 겪는 대상 — 90초

- `[작성]` 가장 먼저 돕고 싶은 사용자와 구체적인 운영 상황
- `[작성]` 반복 작업, 장애 대응, 운영 불확실성 중 이번 시즌에 다룰 문제
- `[확인]` 사용자 인터뷰나 실제 사례, 관찰한 비용·빈도와 출처
- 조사 전 가설과 확인된 사용자 요구를 구분

## 3. 현재 해결 방식과 기존 오픈소스의 한계 — 90초

- `[작성]` 대상 사용자가 현재 사용하는 수동 절차, 스크립트, 배포 도구
- `[확인]` 비교할 기존 오픈소스와 버전, 공식 문서 또는 재현 결과
- `[작성]` 각각 해결하는 범위와 이 사용 사례에서 남는 작업
- 검증 없이 “대안 없음”, “유일”, “완전 자동화”로 단정하지 않음

## 4. 팀이 제안하는 해결 방법 — 90초

- `[작성]` 사용자가 원하는 상태를 정의하고 운영 상태를 확인하는 흐름
- `[작성]` 핵심 사용 사례 하나의 변경 전·후 모습과 성공 조건
- `[확인]` 제안 범위, 이미 구현한 기능, 검증한 동작을 나누어 표시
- `[확인]` 장애 처리 시 CUBRID와 Operator 각각의 책임을 ADR에 맞게 설명

## 5. 아키텍처 초안 — 120초

- `[확인]` 연동할 플랫폼과 버전, 저장소의 DESIGN.md 및 ADR 근거
- `[작성]` 사용자 요청 → Kubernetes 리소스 → 제어 구성 요소 → CUBRID의 연동 흐름
- `[작성]` 주요 구성 요소와 상태 관찰·판단·변경의 흐름을 도식화
- `[작성]` 애플리케이션의 DB 데이터 경로와 제어·상태 정보 경로를 구분
- `[확인]` 관찰이 불완전하거나 구성 요소가 실패했을 때의 동작과 안전 경계
- 근거: `[커밋 / 문서 경로 / 확인일]`

## 6. 12주 로드맵, 팀원별 역할, 첫 버전 공개 범위 — 90초

시작일과 종료일: `[확인]`. 아래 4개 구간은 작성 틀이며 합의된 일정이 아닙니다.

| 4–6주 | [작성] | [확인] | [작성] |
| 7–9주 | [작성] | [확인] | [작성] |
| 10–12주 | [작성] | [확인] | [작성] |

- `[확인]` 시즌 종료 시 공개할 첫 버전의 기능·지원 환경·문서·테스트 범위
- `[확인]` 첫 버전의 완료 조건과 범위 밖 항목

## 7. 함께 논의하거나 의견을 구하고 싶은 내용 — 60초

- `[작성]` 검증받고 싶은 사용자·문제 가설 1개
- `[작성]` 첫 버전 범위 또는 아키텍처에서 조언받고 싶은 결정 1개
- `[작성]` 사용자 피드백, 테스트 환경, 운영 경험 중 필요한 도움
- 질의응답용 근거 자료와 미확인 질문은 별도 메모로 준비
