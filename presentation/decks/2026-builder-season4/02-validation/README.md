# 빌더 시즌4 2차 검증 발표

[한국어](slides.ko.md)와 [영어](slides.en.md)는 각각 본편 18장, 질의응답 1장, 부록 4장입니다.

`presentation/`에서 `npm run dev:operator2:ko` 또는 `npm run dev:operator2:en`으로 미리 볼 수 있습니다. 한국어는 `npm run export:operator2:pdf`와 `npm run export:operator2:pptx`, 영어는 `npm run export:operator2:en:pdf`와 `npm run export:operator2:en:pptx`로 출력합니다. 출력물은 발표자료 내보내기 워크플로에 첨부됩니다.
