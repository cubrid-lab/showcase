# 빌더 시즌4 2차 검증 발표 초안

[한국어 원본](slides.ko.md)은 총 24장입니다. 21장까지 본문과 Q&A이며, 마지막 3장은 상세 구조·시험 비교·관측 조건 부록입니다. 도표·검증 현황·릴리스 계획·팀 역할·후속 계획은 본문에 포함합니다.

아직 제출하거나 릴리스한 PDF/PPTX는 없습니다. 출력물은 Git에 넣지 않고 CI 아티팩트로 검토합니다. 병합하면 등록된 HTML 경로가 기존 Pages 배포 절차로 게시됩니다.

`presentation/`에서 `npm run dev:operator2:ko`, `npm run build:operator2`, `npm run export:operator2:pdf`, `npm run export:operator2:pptx`로 확인합니다.
